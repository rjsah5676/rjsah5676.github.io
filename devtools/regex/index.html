정규식 테스터

허용할 문자

입력 중에 글자를 지우는 필터로 쓸 거면 '한글 낱자'도 켜세요. 조합 중인 ㄱ이 지워져서 한글이 안 써집니다.

허용할 특수문자 (그대로 입력)
길이 (비우면 제한 없음)
~자
반드시 1개 이상 포함
결과
정규식/^[a-zA-Z0-9가-힣]{2,10}$/
JS 검사/^[a-zA-Z0-9가-힣]{2,10}$/.test(value)
JS 입력 필터value.replace(/[^a-zA-Z0-9가-힣]/g, "")
Java 검사value.matches("^[a-zA-Z0-9가-힣]{2,10}$")
Java 입력 필터value.replaceAll("[^a-zA-Z0-9가-힣]", "")

검사는 값 전체가 조건에 맞는지(제출할 때), 입력 필터는 허용 안 되는 글자를 바로 지울 때(입력할 때) 씁니다. 필터는 길이·포함 조건까지는 못 챙기니 제출 때 검사도 같이 하세요.

Java 코드
Pattern pattern = Pattern.compile("[\\w.+-]+@([\\w-]+\\.)+[A-Za-z]{2,}");
Matcher matcher = pattern.matcher(text);
while (matcher.find()) {
    String found = matcher.group();
}

사용법

  1. 검증 테스트 — 폼 검증에 쓰는 정규식(/^[가-힣a-z]*$/ 같은)을 붙여넣고 값을 입력하면 통과 여부와 걸린 글자, 길이·포함 조건 중 뭐가 틀렸는지 보여줍니다. 허용 문자 목록은 \uAC00 같은 코드도 사람 말로 풀어줍니다.
  2. '입력 막기'를 켜면 onChange에서 글자를 지우는 필터를 그대로 체험할 수 있고, 여러 값을 줄마다 넣어 한 번에 검사할 수도 있습니다.
  3. 정규식 만들기 — 허용할 문자·길이·필수 포함 조건을 고르거나 휴대폰·이메일 같은 형식을 고르면 정규식과 JS/Java 검사·필터 코드가 나옵니다.
  4. 찾기·치환 — 로그나 텍스트에서 매칭을 하이라이트하고 캡처 그룹, 치환 결과, Java Pattern 코드를 확인합니다.

자주 묻는 질문

Q.어떤 정규식 문법을 쓰나요?

브라우저의 JavaScript 정규식(ECMAScript)으로 실행합니다. 대부분의 문법은 Java와 같지만 몇 가지가 다릅니다. 아래 'JavaScript와 Java의 차이' 표를 참고하세요.

Q.Java 코드에 넣으려면 역슬래시를 두 번 써야 하잖아요.

아래 Java 코드 영역이 \d → \\d 처럼 자동으로 이스케이프한 문자열과 Pattern.compile 코드를 만들어 줍니다. 반대로 Java 소스에 있던 "\\d+" 를 그대로 붙여넣고 싶으면 'Java 문자열로 입력'을 켜세요.

Q.페이지가 멈추지 않나요?

정규식은 별도 스레드(Web Worker)에서 실행하고, 1초 안에 끝나지 않으면 강제로 중단합니다. (a+)+$ 같은 중첩 반복은 입력이 조금만 길어도 계산량이 기하급수적으로 늘어나는데(재앙적 역추적), 서버에서 쓰면 ReDoS 공격 대상이 되니 이 경고가 뜨면 패턴을 고치는 게 좋습니다.

Q.입력한 내용이 서버로 전송되나요?

아니요. 모든 계산은 브라우저 안에서 이루어지고, 마지막 입력값만 이 브라우저의 localStorage에 저장해 다음에 다시 열었을 때 복원합니다.

Q.g 플래그를 끄면 왜 하나만 나오나요?

g(global)가 없으면 정규식은 첫 번째 매칭에서 멈춥니다. 치환도 첫 번째만 바뀝니다. Java로 치면 g가 있으면 while(matcher.find()) / replaceAll, 없으면 if(matcher.find()) / replaceFirst에 해당합니다.

로그에서 쿼리를 뽑았다면 MyBatis 로그 → SQL로 파라미터까지 채워보세요.
