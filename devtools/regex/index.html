정규식 테스터

입력하는 대로 매칭을 하이라이트하고 그룹을 보여줍니다. 치환 미리보기와 Java 코드 변환까지.

예시
정규식
//g
테스트 문자열
매칭 결과 
문의: gunmo.dev@example.com, 잘못된 형식: user@@test, 회사: lee+work@corp.co.kr
매칭 목록

매칭되는 부분이 없습니다.

Java 코드
Pattern pattern = Pattern.compile("[\\w.+-]+@([\\w-]+\\.)+[A-Za-z]{2,}");
Matcher matcher = pattern.matcher(text);
while (matcher.find()) {
    String found = matcher.group();
}

사용법

  1. 정규식과 테스트 문자열을 넣으면 매칭된 부분이 바로 하이라이트됩니다.
  2. 오른쪽 표에서 매칭마다 위치와 캡처 그룹($1, $2, 이름 그룹)을 확인할 수 있습니다.
  3. 치환을 켜면 바꾼 결과를 미리 볼 수 있습니다.
  4. 맨 아래 Java 코드를 복사해서 바로 쓰거나, Java 소스에 있던 정규식 문자열을 'Java 문자열로 입력'을 켜고 그대로 붙여넣어 테스트하세요.

자주 묻는 질문

Q.어떤 정규식 문법을 쓰나요?

브라우저의 JavaScript 정규식(ECMAScript)으로 실행합니다. 대부분의 문법은 Java와 같지만 몇 가지가 다릅니다. 아래 'JavaScript와 Java의 차이' 표를 참고하세요.

Q.Java 코드에 넣으려면 역슬래시를 두 번 써야 하잖아요.

아래 Java 코드 영역이 \d → \\d 처럼 자동으로 이스케이프한 문자열과 Pattern.compile 코드를 만들어 줍니다. 반대로 Java 소스에 있던 "\\d+" 를 그대로 붙여넣고 싶으면 'Java 문자열로 입력'을 켜세요.

Q.페이지가 멈추지 않나요?

정규식은 별도 스레드(Web Worker)에서 실행하고, 1초 안에 끝나지 않으면 강제로 중단합니다. (a+)+$ 같은 중첩 반복은 입력이 조금만 길어도 계산량이 기하급수적으로 늘어나는데(재앙적 역추적), 서버에서 쓰면 ReDoS 공격 대상이 되니 이 경고가 뜨면 패턴을 고치는 게 좋습니다.

Q.입력한 내용이 서버로 전송되나요?

아니요. 모든 계산은 브라우저 안에서 이루어지고, 마지막 입력값만 이 브라우저의 localStorage에 저장해 다음에 다시 열었을 때 복원합니다.

Q.g 플래그를 끄면 왜 하나만 나오나요?

g(global)가 없으면 정규식은 첫 번째 매칭에서 멈춥니다. 치환도 첫 번째만 바뀝니다. Java로 치면 g가 있으면 while(matcher.find()) / replaceAll, 없으면 if(matcher.find()) / replaceFirst에 해당합니다.

로그에서 쿼리를 뽑았다면 MyBatis 로그 → SQL로 파라미터까지 채워보세요.
