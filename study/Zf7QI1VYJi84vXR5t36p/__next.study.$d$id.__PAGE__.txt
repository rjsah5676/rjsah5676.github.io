N이 최대 10<sup>5</sup>라 배열을 만들 수 없다.</p><h2>질문을 뒤집기</h2><p>"K번째 수는 무엇인가?" 대신 "<strong>x 이하인 수는 몇 개인가?</strong>"를 묻는다. 이 개수는 x에 대해 단조 증가하므로, 개수가 처음으로 K 이상이 되는 가장 작은 x가 답이다. 이렇게 답 자체를 이분 탐색하는 방식을 매개변수 탐색이라고 한다.</p><h2>x 이하인 수 세기</h2><p>i행은 i, 2i, 3i, …, Ni 이므로 x 이하인 개수는 min(x / i, N)개다.</p><div class="ql-code-block-container" spellcheck="false"><div class="ql-code-block" data-language="plain">long long n, k;</div><div class="ql-code-block" data-language="plain">cin &gt;&gt; n &gt;&gt; k;</div><div class="ql-code-block" data-language="plain"><br></div><div class="ql-code-block" data-language="plain">long long lo = 1, hi = k, ans = k;   // 답은 k를 넘지 않는다</div><div class="ql-code-block" data-language="plain">while (lo &lt;= hi) {</div><div class="ql-code-block" data-language="plain">    long long mid = (lo + hi) / 2, cnt = 0;</div><div class="ql-code-block" data-language="plain">    for (long long i = 1; i &lt;= n; i++) cnt += min(mid / i, n);</div><div class="ql-code-block" data-language="plain">    if (cnt &gt;= k) { ans = mid; hi = mid - 1; }</div><div class="ql-code-block" data-language="plain">    else lo = mid + 1;</div><div class="ql-code-block" data-language="plain">}</div><div class="ql-code-block" data-language="plain">cout &lt;&lt; ans;</div></div><h2>왜 답이 k를 넘지 않을까</h2><p>1행에는 1, 2, …, N이 있고 다른 행에도 작은 수가 많아서, k 이하인 수는 항상 k개 이상 존재한다. 그래서 탐색 범위를 [1, k]로 잡을 수 있다.</p><h2>시간 복잡도</h2><p>이분 탐색 O(log K) × 개수 세기 O(N) = O(N log K). 공유기 설치(BOJ 2110), 랜선 자르기(BOJ 1654)도 같은 틀로 풀린다: "답이 x일 때 조건을 만족하는가?"가 단조로우면 답을 이분 탐색한다.</p>8:X
