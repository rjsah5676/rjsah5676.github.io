REST(Representational State Transfer)

웹의 자원을 URI로 표현하고, 자원에 대한 행위는 HTTP 메서드(GET, POST, PUT, DELETE) 를 통해 처리하는 아키텍처 스타일

그래서 RESTful은 이 원칙을 잘 지켜서 설계된 API를 일컫음

RESTful하게 API를 설계하면 가독성, 유지보수성, 재사용성이 좋아지고 프론트엔드와 백엔드 간의 통신이 표준화 됨.


예를 들어, /users라는 URI는 "유저 자원"을 의미하고

GET /users는 유저 목록 조회, POST /users는 유저 생성,

GET /users/1은 1번 유저 조회, DELETE /users/1은 1번 유저 삭제처럼 명확하고 일관성 있는 방식으로 처리됨
