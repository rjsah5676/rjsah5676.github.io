HTTP(Hyper Text Transfer Protocol)란?

- 웹에서 클라이언트와 서버가 데이터를 주고받기 위해 사용하는 통신 프로토콜

- 기본적으로 요청(Request) - 응답(Response) 구조로 동작

중간에 데이터가 탈취되거나 위/변조 위험을 방지할 수 있다.



TCP & UDP

TCP: 연결을 설정한 뒤 데이터를 전송하고, 수신 여부를 확인하며 정확히 전송함.

→ 신뢰성 최우선, 속도는 느릴 수 있음

UDP: 연결 없이 데이터만 툭툭 던짐. 순서나 수신 확인 안 함.

→ 빠르지만, 데이터 손실 가능성 있음


여기서 3-way handshake란?

- TCP 연결을 맺기 위한 3단계 과정

- 클라이언트와 서버가 서로 통신 가능함을 확인하고 연결을 확립하는 절차

- 클라이언트가 SYN을 던지고 서버가 SYN+ACK으로 응답 후 클라이언트가 최종적으로 ACK을 보냄

- 연결 해제시에는 4-way로 함


Web Server? WAS?

WAS (Web Application Server) 는 동적인 웹 페이지를 처리하는 서버 소프트웨어.

단순히 정적인 HTML 파일만 보여주는 게 아니라, 사용자의 요청에 따라 로직을 처리하고 DB에서 데이터를 가져와 결과를 만들어주는 역할

1. 사용자가 브라우저에서 /login 페이지에 로그인 요청을 보냄

2. 웹 서버(Nginx) 가 이 요청을 받아 WAS(Tomcat) 에 전달

3. WAS가 자바(Spring) 로직 실행 + DB에서 사용자 정보 조회

4. 결과를 만들어서 사용자에게 HTML 응답으로 전송
